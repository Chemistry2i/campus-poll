🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════

STEP 1: READ (5 minutes)
   → Open: INDEX.md or ACCESSIBILITY_QUICK_REFERENCE.md

STEP 2: SETUP GOOGLE CLOUD (10 minutes)
   → Create project at console.cloud.google.com
   → Enable Text-to-Speech API
   → Create Service Account
   → Download credentials JSON

STEP 3: INSTALL & CONFIG (5 minutes)
   → cd backend && npm install @google-cloud/text-to-speech
   → Add GOOGLE_APPLICATION_CREDENTIALS to .env

STEP 4: WRAP APP (5 minutes)
   → Import AccessibilityProvider in App.jsx
   → Wrap your app with it

STEP 5: ADD COMPONENTS (30 minutes)
   → Add AccessibilitySettingsPanel to navbar
   → Add TextToSpeechButton to candidate cards
   → Add SpeechToTextButton to voting modal

TOTAL TIME: ~1 hour to fully working!
